# Baseline, 2026-10-14: what `wisp` does, with proof

After M0 removed every front end but the CLI and the REPL (PR #152). Every claim below is a test
that runs the real command (`python -m wisp`, under a pty for the REPL) against a scripted local
model (`tests/baseline/_model.py`), with no fake core and no injected executor. CI runs these tests
on every change, so this page stays true or a test goes red.

```bash
python -m pytest -q tests/baseline -rxX                  # scripted model, about 40 s
python -m pytest -q -m live tests/baseline/test_live_smoke.py   # your real provider, not in CI
```

## Defects found by proving it

| # | Defect | Cause | State |
|---|---|---|---|
| D1 | `--print` repeated every draft the harness rejected ("Done. All tests pass." six times) | The result joined every round's text | fixed: the answer is the last round |
| D2 | After `n` to a write, the REPL still says "this turn changed code", nudges for verification, and lists the file | `wrote_code` means "attempted", and both the acceptance verdict and the user-facing notes read it | **pinned** (strict xfail): splitting attempted from applied is M1, the single finish judge |
| D3 | Every `--print` run in a workspace joined one stored conversation | Default session id `"headless"` | fixed: `headless-<hex>` per run |
| D4 | `--print` reported `"iterations": 0` | The engine's done event never carried the count | fixed |
| D5 | A failed `--print` exited 0 | Exit status was set only on an exception | fixed: exits 1 |
| D6 | The model was told `sandbox: docker` with `WISP_SANDBOX=off` | Boot posture checked only for a docker binary | fixed: off is `host-unconfined`; the docker line states the no-daemon fallback |
| D7 | A tool the model was not offered still ran (`spawn`, `git_commit` under the default profile) | The profile narrowed the offer only, by design | fixed: what is offered is what may be called, for every profile |

Each fix was shown failing on the old code first. D2's pin fails today for exactly its stated
reason (`--runxfail`). Fixing D2 makes that pin pass, and a strict xfail that passes fails the
suite, so this table has to be updated.

## Measured, not yet acted on

- **Compaction settings that nothing reads:** `auto_compact`, `compact_threshold_tokens` and `compact_mode`. Compaction is by message count (50). `compact_keep_recent` is read only by `/compact`. For the dead-code pass.
- **A quiet provider fallback:** without `provider` in `config.json`, a model named `nvidia/...` goes to local Ollama, even with `NVIDIA_API_KEY` set. The 404 says so.
- **Verification on the owner's machine:** `python` in `run_bash` was the Anaconda `litllm` env, whose pytest crashes on a plugin. The model made 21 shell calls before using `run_tests`. Steering verification toward `run_tests` is a cheap win, measurable with the live smoke.
- **Two finish judges:** on B3's path the reasoning core's R1 writes the note; on D2's path honest_finish does. This is M1.
