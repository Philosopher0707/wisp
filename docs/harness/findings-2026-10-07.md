# Findings register, 2026-10-07

One place for every finding from the invariant-gates, reasoning-core, background-jobs, CI and interpreter-level work of this session. Each row says **how it was established**, how serious it is, and its **status**. Nothing here is rounded up: "verified" means a real run with output; "read" means seen in the code only; "unverified" means not checked.

Severity: **High** = can make Wisp report something false as verified, or exposes a secret to untrusted code; **Medium** = leaks resources or gives the model a misleading result; **Low** = process or tooling hazard.
